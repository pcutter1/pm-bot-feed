# PM-BOT Counsel Feed

This repository publishes the latest PM-BOT counsel packet URL.

## Usage

Fetch the latest counsel packet URL:
```
curl https://pcutter1.github.io/pm-bot-feed/counsel/latest.txt
```

This returns a direct-download Google Drive URL for today's counsel packet.

## Automation

Updated daily by `make pm-counsel` in the pm-bot repository.
